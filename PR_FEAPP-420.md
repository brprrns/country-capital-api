# PR Title

feat/FEAPP-420: Add WhatsApp customer notifications

## WHAT:

Added optional WhatsApp notification support for product listing updates.

Customers who provide a WhatsApp number will receive product update notifications through both email and WhatsApp.

## WHY:

Customers requested WhatsApp as an additional notification method for product listing updates.

The WhatsApp notification option is optional, while the existing email notification functionality remains supported.

## Notes:

- WhatsApp notifications are sent when a WhatsApp number is provided.
- Existing email notifications continue to work.
- The changes are made from a branch created from the main development branch.
- The changes should include appropriate tests for the WhatsApp notification functionality.
