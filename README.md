# Country Capital API

## Overview

Country Capital API is a Python Flask API that returns the name of a country when a capital city is provided.

The API is served using Uvicorn and is available as a microservice endpoint.

## Prerequisites

Before running the API locally, make sure you have:

- Python 3.x installed
- pip installed
- Git installed
- Flask
- Uvicorn
